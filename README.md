The code reproduces the AWGN BER results (Fig. 2), Rayleigh BER results (Figs. 3-5) and the PAPR results (Fig. 6).



Developed for MATLAB R2024b; 

no toolbox is needed (the Parallel Computing Toolbox, if installed, speeds up the Rayleigh simulation).

## Start

```matlab
main_awgn_ber        % -> results_awgn/      (png, fig)
main_rayleigh_ber    % -> results_rayleigh/  (png, fig)
main_papr_ccdf       % -> results_papr/      (png, fig)
```
